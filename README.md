# Games2D

**Games2D** is the SWIR monorepo for original Unity 2D/2.5D games. Each game lives in its own complete Unity project under `games/`.

## Games

| ID | Game | Status | Project |
|---:|---|---|---|
| 001 | **SCRAP DASH** | Early development | `games/001_scrap_dash/` |

## Repository layout

```text
games/
  001_scrap_dash/
    Assets/
    Packages/
    ProjectSettings/
    README.md
    ROADMAP.md
```

Each game owns its own Unity project, gameplay code, assets, tests, roadmap and Windows build workflow.

## Rules

- Original games and legally usable assets only.
- Unity-generated `Library/`, `Temp/`, `Logs/`, `Obj/` and `Builds/` are not committed.
- Secrets and Unity license data stay in GitHub Actions secrets.
- Windows builds are considered verified only after real Unity CI succeeds.
